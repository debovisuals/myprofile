# DeboVIsuals portfolio

A responsive photography and drone-services portfolio built with React, Vite, Framer Motion and Lucide icons.

## Run locally

1. Install Node.js (18 or newer).
2. From this project folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.
4. Run `npm run build` to create the production site in `dist/`.

## Update the content

- **WhatsApp, email, brand and social profiles:** edit `src/config/siteConfig.js`. Replace the WhatsApp placeholder with your international number using digits only, without a plus sign or spaces. The WhatsApp links are all generated by `src/utils/whatsapp.js`.
- **Portfolio:** edit `src/data/projects.js`. Images and video paths are relative to `public/`; for example, `/images/photography/my-project.jpg` and `/videos/drone/my-film.mp4`. Video projects should use `type: "video"` and include a `video` path.
- **Services:** edit `src/data/services.js`.
- **Packages:** edit `src/data/packages.js`. All included prices and packages are marked as samples; replace these placeholders with confirmed business details.
- **About and contact copy:** edit the components in `src/sections/`.
- **Images and videos:** add your files to the descriptive folders under `public/images/` or `public/videos/`, then update their paths in the data files. If an image is missing, the site displays `public/images/image-fallback.svg`.

The contact form opens WhatsApp with the visitor's name, email and message. It does not save or submit form data to a server. No payment processing is included.
Portfolio cards are sample entries, and the About section includes copy for you to personalize. Replace those before publishing.
