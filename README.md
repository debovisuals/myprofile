# DeboVIsuals portfolio

A responsive photography and drone-services portfolio built with React, Vite, Framer Motion and Lucide icons.

## Run locally

1. Install Node.js (18 or newer).
2. From this project folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.
4. Run `npm run build` to create the production site in `dist/`.

## Update the content

- **WhatsApp, email, brand and social profiles:** edit `src/config/siteConfig.js`. The WhatsApp buttons use the configured `whatsappUrl`, and the contact form sends to the configured `email`; WhatsApp links are generated by `src/utils/whatsapp.js`.
- **Add completed projects:** add a project object to the `projects` array in `src/data/projects.js`; every entry is shown in the Portfolio gallery. Give each project a unique `id`, `title`, `category`, `location`, `description`, `type`, `image`, and `imageAlt`. Put image files in `public/images/` and use paths starting with `/images/`. For video projects, set `type: "video"` and add a `video` path starting with `/videos/`; `image` is used as the video poster. The existing entries are samples you can replace or remove.
- **Services:** edit `src/data/services.js`.
- **Packages:** edit `src/data/packages.js`. Portrait, event and brand packages are samples; convocation prices and picture counts are listed as provided.
- **About and contact copy:** edit the components in `src/sections/`.
- **Images and videos:** add your files to the descriptive folders under `public/images/` or `public/videos/`, then update their paths in the data files. If an image is missing, the site displays `public/images/image-fallback.svg`.

The contact form opens the visitor's email app with their name, email and message addressed to the configured business email. It does not save or submit form data to a server. No payment processing is included.
Portfolio cards are sample entries, and the About section includes copy for you to personalize. Replace those before publishing.
